# AMBURAX POS — Integration Strategy

## Wave 1
Shopify.

## Wave 2
Amazon + Flipkart.

## Wave 3
WooCommerce + IndiaMART/B2B.

## Wave 4
Meesho + ONDC only after verifying official access and supported use cases.

## Wave 5
Fashion marketplaces such as Myntra/AJIO/Nykaa as commercially justified.

## Connector requirements
Auth, capabilities, credential vaulting, listings, inventory, orders, fulfillment, returns, webhooks/polling, retry, rate-limit handling, idempotency, dead-letter queue, sync status, reconciliation and reconnect.

## Critical strategy
External seller accounts do not automatically equal unrestricted API access. At implementation time use the provider's current official developer/partner requirements.

IndiaMART belongs primarily in B2B/CRM.
