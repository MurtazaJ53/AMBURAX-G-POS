# AMBURAX POS — Core Flows

## POS
Scan/Search -> Variant -> Cart -> Customer -> Discount/Tax -> Payment -> Validate -> ERPNext -> Success -> Receipt/View Bill

## Return / Exchange
Bill -> Item -> Eligibility -> Return/Exchange -> ERPNext -> Stock/Accounting reconciliation

## Inventory
Search/Scan -> Variant -> Location -> Stock -> Adjust/Transfer/Replenish

## Commerce Connect
Connect -> Authorize -> Capabilities -> Schema -> Mapping -> Validate -> Preview -> Publish -> External IDs -> Sync

## Online Order
Webhook/Poll -> Validate -> Normalize -> Canonical Order -> Allocate -> Fulfill -> ERPNext if required -> Status sync

## B2B
Lead -> Qualify -> Assign -> Follow-up -> Quote -> Sales Order -> Customer -> Invoice -> Payment

## AI
Data -> Detect -> Explain -> Recommend -> Policy -> Approval -> Execute -> Verify -> Audit
