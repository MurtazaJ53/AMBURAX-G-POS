# AMBURAX POS — UI Design System

## Visual baseline
Premium light SaaS, white/light backgrounds, blue primary action, semantic accents, rounded cards, subtle borders/shadows, readable enterprise tables, garment thumbnails, persistent desktop sidebar, global search and store/shift context.

## Interaction
Use drawers, tabs, wizards, command palette and quick actions to avoid unnecessary page explosion.

## States
Every major surface: loading, empty, error, permission denied, success, retry.

## Garment UX
Style, size, color, variant, SKU, barcode, location stock, MRP, selling price, discount and tax.
