# AMBURAX POS — Final Master Documentation

Amburax POS is a garment-first Business Commerce Operating System built on ERPNext Core.

## Full vision
Retail POS + Catalog + Inventory + CRM + Khata + Purchasing + Store Operations + Commerce Hub + Marketplaces + B2B + Analytics + AI Automation + Multi-Store.

## Locked scope
125 primary screens/workspaces. The original retail/ERP foundation is preserved in full; Commerce, B2B, AI, integration, reconciliation and enterprise capabilities expand it.

## Architecture principle
ERPNext = authoritative ERP transaction/stock/accounting system.
Amburax = retail UX, commerce orchestration, channel engine, B2B, AI, automation, analytics, reconciliation and mobile experience.
